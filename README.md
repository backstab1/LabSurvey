# SurveyLAB

Сервис опросов для команды: конструктор анкет, импорт анкеты из JSON (в том числе сгенерированного ИИ), прохождение с телефона, выгрузка в Excel, SPSS (.sav) и Google Sheets.

## Возможности

- **Типы вопросов:** один ответ, несколько ответов, выпадающий список, открытый текст, число, шкала / NPS, матрица (один или несколько ответов в строке, обязательность всех строк / N строк / необязательно), дата, телефон, информационный блок, скрытая переменная.
- **«Другое (укажите)»** в любых вариантах и в строках матрицы; эксклюзивные варианты («Ничего из перечисленного»).
- **Один вопрос на экран**, вопросы сгруппированы в блоки. Вся логика — на уровне вопроса.
- **Логика без кода (действия, как в Survey Studio):** условие показа (И / ИЛИ / НЕ); перед показом — скрыть / оставить варианты, скрыть варианты по другому вопросу, пропустить при малом числе вариантов, отметить ответ без показа, записать переменную; после ответа — перейти к вопросу или блоку, завершить, отсеять, записать переменную, показать ошибку.
- **Настройки вопроса** (свёрнуты в окне вопроса): рандомизация / ротация, скрыть «Назад» / «Завершить», перевёрнутая таблица, вертикальные заголовки, строки по мере ответа, карусель, дробные числа, e-mail / время, запрет вставки, автопереход, поле «Другое» всегда видно.
- **Пайпинг** `{{Q1}}`, **перенос вариантов** из предыдущих вопросов.
- **Скрипты и CSS** — для того, что не покрывают действия: глобальный скрипт, `onShow` / `onChange` / `validate` у вопроса, свой CSS.
- **Интерфейс респондента:** мобильная вёрстка, прогресс, «Назад», «Завершить досрочно» (отключаются в настройках), Enter — «Далее», продолжение с места остановки после перезагрузки.
- **Конструктор:** лента карточек в том виде, как их увидит респондент; клик по карточке открывает окно вопроса (варианты / строки и столбцы по типу, предпросмотр, свёрнутые «Действия» и «Настройки»); «+» между карточками, перетаскивание, быстрый ввод вариантов (Enter, вставка списка).
- **JSON ⇄ конструктор** синхронизируются в обе стороны. Кнопка «Скопировать инструкцию для ИИ» копирует документацию формата вместе с заданием.
- **Черновик сохраняется автоматически**; респонденты видят изменения только после публикации; предпросмотр пишет тестовые ответы отдельно.
- **Данные:** SQLite, метаданные (время начала и окончания, длительность, IP, User-Agent, параметры ссылки/UTM, статус), выгрузка в Excel (коды, метки, кодбук), SPSS .sav (метки переменных и значений, типы шкал), автоматическая запись в Google Sheets.

Формат анкеты: [docs/survey-format.md](docs/survey-format.md). Пример: [examples/demo.json](examples/demo.json).

## Запуск локально

Нужен Node.js 22.5+ (рекомендуется 24).

```bash
npm install
cp .env.example .env      # укажите ADMIN_PASSWORD
npm run dev               # сервер :3000 + фронтенд :5173 с автоперезагрузкой
```

Админка: http://localhost:5173/admin, опрос: `/s/<id>`.

Тесты: `npm test` (тест .sav использует Python + pyreadstat, если они установлены, иначе пропускается). Проверка типов: `npm run typecheck`.

## Установка на VPS (Ubuntu)

```bash
# Node.js 24
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo -E bash -
sudo apt install -y nodejs git

git clone https://github.com/backstab1/LabSurvey.git /opt/surveylab
cd /opt/surveylab
npm ci
npm run build
cp .env.example .env && nano .env      # ADMIN_PASSWORD, NODE_ENV=production
```

Служба systemd `/etc/systemd/system/surveylab.service`:

```ini
[Unit]
Description=SurveyLAB
After=network.target

[Service]
WorkingDirectory=/opt/surveylab
Environment=NODE_ENV=production
ExecStart=/usr/bin/npm start
Restart=always
User=www-data

[Install]
WantedBy=multi-user.target
```

```bash
sudo chown -R www-data /opt/surveylab
sudo systemctl enable --now surveylab
```

Пока нет домена, сервис доступен по `http://<IP>:3000`. В этом режиме задайте в `.env` `COOKIE_SECURE=0`, иначе браузер не сохранит cookie входа без HTTPS. Когда появится домен, поставьте nginx с HTTPS (certbot), проксируйте на `127.0.0.1:3000`, задайте `TRUST_PROXY=1` (чтобы IP респондентов записывался правильно) и уберите `COOKIE_SECURE=0`.

Данные лежат в `data/surveylab.db`. Резервная копия — просто копия этого файла (`sqlite3 data/surveylab.db ".backup backup.db"`).

## Google Sheets

1. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект, включите **Google Sheets API**.
2. Создайте **сервисный аккаунт**, выпустите для него ключ JSON, положите файл на сервер (например, `/opt/surveylab/google-key.json`).
3. В `.env`: `GOOGLE_APPLICATION_CREDENTIALS=/opt/surveylab/google-key.json`, перезапустите сервис.
4. Откройте нужную таблицу на **редактирование** для email сервисного аккаунта (он показан во вкладке «Данные» анкеты).
5. Во вкладке «Данные» вставьте ссылку на таблицу и нажмите «Полная синхронизация». Если включено «Дописывать каждого нового респондента», новые анкеты будут добавляться автоматически. Если структура столбцов изменилась, лист перезаписывается целиком.

## Архитектура

```
shared/   формат анкеты, логика (условия, действия, переходы, пайпинг, перенос), проверка ответов, модель переменных выгрузки,
          перевод старых версий формата (migrate.ts)
          — один и тот же код работает в браузере и на сервере
server/   Fastify + node:sqlite; API прохождения (сервер — источник истины: проверяет ответы и решает, куда идти),
          API админки, выгрузки (xlsx, sav — собственная реализация без зависимостей), Google Sheets
web/      React: страница опроса /s/:id и админка /admin (конструктор, JSON, настройки, данные)
docs/     документация формата — её же копирует кнопка «инструкция для ИИ»
```

- Методы хранилища асинхронные (`server/db.ts`), поэтому переход на PostgreSQL затронет только этот файл.
- Сохранённые ответы очищаются от «брошенных веток»: если респондент вернулся назад и сменил путь, ответы на вопросы, которые он больше не видит, в выгрузку не попадут.
- При переопубликации незавершённые респонденты продолжают по новой версии; номер версии пишется в выгрузку.

## Дальше (заложено в формате и архитектуре)

- **Несколько вопросов на одном экране** — опция блока (формат это допускает: движок уже работает с «экранами»).
- **Серверные скрипты** (обработка после завершения, вебхуки, квоты) — будут выполняться на сервере в изолированной среде (isolated-vm). Клиентские хуки и действия уже работают.
- **Квоты** и **панель респондентов** — через скрытые переменные и параметры ссылки уже можно передавать ID панелиста и группы.
- **Многопользовательский доступ** с ролями (сейчас один общий вход команды).
- **Генерация анкеты ИИ прямо в сервисе** — подключение LLM на ваш выбор; формат и валидатор уже готовы.
- Логотип и фирменные цвета — сейчас через CSS анкеты.

## Безопасность

- Скрипты анкет выполняются в браузере на том же домене, что и админка. Писать скрипты может только команда; не вставляйте код из непроверенных источников.
- Сервер всегда сам проверяет ответы, поэтому скрипты не могут записать некорректные данные в обычные вопросы.
